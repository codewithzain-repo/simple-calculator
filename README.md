# 🧮 Simple Arithmetic Calculator

A clean, responsive, and beautifully styled web-based calculator built using **HTML5**, **CSS3**, and **JavaScript**. 

## ✨ Features
- Performs basic arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Fully responsive layout for both mobile and desktop screens
- Modern UI with custom color palette and smooth hover/focus effects
- Clean and error-free JavaScript logic using event listeners and switch/conditional logic

## 🚀 Technologies Used
- **HTML5** (Structure)
- **CSS3** (Styling, Flexbox, Responsive Design)
- **JavaScript (ES6)** (Calculator Logic & DOM Manipulation)
